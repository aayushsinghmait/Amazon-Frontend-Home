# Amazon-Frontend-Home
Amazon-inspired e-commerce homepage built with **HTML, CSS, and JavaScript**. Created in **July 2026** to practice front-end development, responsive design, UI styling, and JavaScript interactions. 🚀💻
## 🚀 How to Open

To view the Amazon Home Page Clone:

1. Download or clone this repository.
2. Open the project folder.
3. **Click on `Amazon.html`**.
4. The webpage will automatically open in your default browser.

👉 **Simply click `Amazon.html` to launch the project in your browser.**
